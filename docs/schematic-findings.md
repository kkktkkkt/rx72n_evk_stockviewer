## 1. UART(CN8 = COM7)の接続先 ◎〜○

経路: CN8(USB) → ボード上のUSB-シリアル変換マイコン U9 (R5F10JBCANA, RL78) → レベル変換 U11/U12 → アナログスイッチ U10 (74CBTLV3257) → RX72N または ESP32。

| 項目 | 内容 |
|---|---|
| **既定の接続先** | **RX72N の SCI2**。`P13 = TXD2`(RX72N→PC)、`P12 = RXD2`(PC→RX72N)。 |
| 切り替え | U10 の S 端子は ESP32 の IO0 線(R69 4.7kΩで3.3Vにプルアップ)。通常はHで RX72N側(B2)を選ぶ。ユーザーズマニュアル表5-2では **SW3 の2ch(ディップスイッチ)がOFF = RX72N側(既定)、ON = Wi-Fi側** → SW3 2chはOFFのままにする(回路図の S 線をLowにする操作に相当) |
| 確度 | 配線は◎。S=H で B2 が選ばれる向きは、74CBTLV3257 の一般仕様に基づく(○)。実機でCOM7に出力して最終確認 |
| 補足 | SCI1(P30/P26/P31/P27)は **ESP32(Wi-Fi)専用**(p.7)。ログには使えない |
| SC設定 | `r_sci_rx` で **CH2を有効**、TXD2=P13、RXD2=P12。CH1は不要なら無効 |

## 2. タッチパネル(FT5206)のI2C ○

| 信号 | RX72Nの端子 | 備考 |
|---|---|---|
| SCL | **P33 / SSCL6** | SCI6 の簡易I2C |
| SDA | **P32 / SSDA6** | |
| タッチ割り込み(INT) | P34 / IRQ4(CN2 の端子6) | ○ |
| タッチリセット(RST) | P66(CN2 の端子5) | ○ 機能名は回路図上に明記なし。確認要 |

→ ドライバは **`r_sci_iic_rx`(チャネル6)** で確定。RIICではない。

## 3. バックライト ◎

`P67_BACKLIGHT_ENA`(ネット名。ピン番号は未確認) = バックライト駆動ICのPWM/EN入力。PWM調光も可能な入力だが、まずは **GPIO出力のHighで点灯** とする。
